# 复习稿（版本2）

生成可独立阅读的中文复习稿，把真实教学对话及选定资料组织为教材，不能逐字复刻聊天。以 inScope 和 ownedConcepts 为主干，prerequisites 与 reusedConcepts 仅提供最小补足；outOfScope 不扩写。已有 introductory 评估仅校准深度，不改变客观范围。

输入 checkpoint 记录上次成功总结的对话位置及已实际阅读的资料范围；conversation 仅含该位置之后本批完整消息，conversationRange 是本批边界，hasMoreConversation 为真时后续还有未处理消息。接着总结本批新内容，不重读已总结对话，不声称已经读完后续内容。currentAsset 是已有完整复习稿：把新增知识融入相应章节，必要时改写或追加，保留仍正确且有用的旧内容；返回融入后的完整文章，不能只返回增量片段。已读资料的范围只对相同 sourceId/revisionId/contentHash 有效，依据 readRanges 继续查阅未覆盖位置。

先说明研究目的，提出3–5个关键问题；建立最小前置，再解释概念、关系、具体样例、假设、证据或技能验证、意义与迁移。错觉和边界必须落实到具体反例。技能主题说明步骤、为什么、限制和可检验行为，理论主题区分经验支持与演绎结论。

正文以二级标题组织现有复习章节，按知识依赖拆分，不按字数或概念数量强制分页，不能恢复旧分页文件协议。每章自包含但避免重复。最后只有一个二级标题“批判性思维总复习”，把八个维度放在这一页内，用三级标题展开；不得把八维拆成八页，不设置总字数、每维字数或句数限额。总复习抓住已学内容的主干、概念关系与必要细节，不逐节复述全部内容，也不写空泛标签。细节由推理所需决定，完整呈现严谨的思维框架：

### 目的
这次学习试图理解或解决什么，为什么值得研究？评价成功的标准是什么？目的与实际问题是否一致？
### 研究问题
提炼贯穿已学内容的核心问题和关键子问题，说明它们之间的关系，区分已回答的问题与仍待检验的问题。
### 信息与证据
指出关键事实、算例、观察或资料如何支持判断；区分直接证据、示例和未经核验的说法，说明证据能支持到哪里。未覆盖的对话、未实际阅读的资料不作为已学事实，不虚构来源。
### 概念与理论
解释支撑推理的核心概念、理论及相互关系，点出易混淆的区别；概念用于解释当前问题，不列孤立术语清单。
### 假设
显式写出推理依赖的前提与简化条件，检查哪些假设有依据，哪些尚未验证，以及条件变化后判断是否仍成立。
### 视角
说明正在采用的解释视角及其局限，比较适用的其他视角。若使用第一性原理，只自然融入本维，不独立开章或铺开第二套逐步推导。
### 推理与结论
把关键证据、概念、假设连接到结论；区分演绎成立、经验支持与暂时推测，指出推理跳跃或可能的反例。结论写明成立条件，不把局部发现推广为无条件规律。
### 意义与后果
说明结论对理解、应用和迁移的意义，可能造成的误用及后果，并给出值得继续检验的问题；不生成学习者掌握程度评语或学习计划。

继续总结时，综合currentAsset与本批新知识更新同一个末尾总复习，保留仍正确的内容、修正有证据反驳的旧结论；不得反复追加多个总复习，不把未处理的后续消息当已总结。MECE分解、概念图、类比按适用性且各最多一次；本复习输出合同优先于primitive示例标题与长度建议。
