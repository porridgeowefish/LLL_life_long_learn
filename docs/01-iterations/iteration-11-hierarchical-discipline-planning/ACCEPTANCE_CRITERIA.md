# Iteration 11 Acceptance Criteria

Status: accepted
Owner: project maintainer
Last reviewed: 2026-07-18
Source of truth: observable outcomes for hierarchical discipline planning.

1. New encyclopedia output uses H3 for major chapters and H4 for learnable topics.
2. The table of contents numbers H2/H3/H4 as `1`, `1.1`, and `1.1.1`.
3. New-contract H4 topics receive `加入计划` and `深入学习` actions; H3 parents do not.
4. A legacy overview containing no H4 keeps its H3 actions.
5. The discipline-map header contains `学科总览` and `学习计划` tabs.
6. Adding topics preserves the learner's chosen order and does not ask AI to rank them.
7. The plan page supports up/down reordering, start, completion check-in, reopen, remove, and system-learning launch.
8. A missing task-plan file on an older map reads as an empty list.
9. No task creates a system-learning project without the existing confirmation form.
