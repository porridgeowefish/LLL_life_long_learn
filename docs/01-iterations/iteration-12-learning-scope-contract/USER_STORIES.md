# User Stories

Status: implemented
Owner: project maintainer
Last reviewed: 2026-07-28

## Stories

1. As a learner starting A.1 from a discipline map, I want the new project to
   know exactly what A.1 includes and excludes, so A.2 remains a distinct study
   commitment.
2. As a learner, I want Intro to adapt depth and examples to my answers without
   changing the topic I selected.
3. As a learner creating a standalone system-learning project, I want the same
   five-zone workflow even though no map has preplanned its boundary.
4. As a map maintainer, I want regenerating a map to leave existing study
   projects stable unless the learner explicitly chooses to update them.
5. As a maintainer, I want invalid or ambiguous topic references rejected before
   a project is created.
