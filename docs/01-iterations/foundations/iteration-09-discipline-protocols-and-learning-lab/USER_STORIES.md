# Iteration 09 User Stories

Status: active
Owner: project maintainer
Last reviewed: 2026-07-15

## US-09-01 Delete a learning project

As a learner, I can choose “删除学习” from a learning project's action menu,
review one clear permanent-deletion warning, and confirm or cancel it.

## US-09-02 Remove associated content

As a learner, after deletion succeeds I no longer see the project, its folder
membership, session history, artifacts, progress, memory, runs, or browser
drafts.

## US-09-03 Protect active work

As a learner, I cannot delete a project while an Agent session for it is still
active, so a running process cannot recreate partially deleted content.

## US-09-04 Understand prerequisite gaps without another action

As a learner, I can read a short explanation of each prerequisite gap directly
in the diagnosis, without clicking a supplement button or waiting for another
AI request.

## US-09-05 Finish with the survey

As a learner, the Intro survey is the final page section, after generated Intro
content and prerequisite diagnosis, so the calibration flow ends at its input
form.
