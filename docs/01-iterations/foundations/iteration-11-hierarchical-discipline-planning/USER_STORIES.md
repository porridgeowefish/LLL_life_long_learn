# Iteration 11 User Stories

Status: active
Owner: project maintainer
Last reviewed: 2026-07-18
Source of truth: learner value delivered by iteration 11.

- As a learner, I see major chapters and finer learnable topics instead of one flat list.
- As a learner, I decide which topic to learn and add it to my task list.
- As a learner, the order in my task list is my choice, not an AI recommendation.
- As a learner, I can move tasks up or down before learning them.
- As a learner, I can start one task, mark it completed, and reopen it if needed.
- As a learner, I can launch the existing system-learning creation flow from a task.
- As an existing learner, my H3-only overview keeps its deep-dive actions until I regenerate it.
