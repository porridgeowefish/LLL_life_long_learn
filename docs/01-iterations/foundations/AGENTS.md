# Delivered-Foundation Reading Rule

This subtree contains implemented foundations that still contribute to LLL.
Do not load every iteration. Select the relevant slice through `README.md`, use
it for provenance and compatibility details, and confirm current behavior in
code, the current iteration, and active architecture documents.

Old status labels and product presentations describe delivery-time context;
they do not override later integration decisions such as the teacher workspace,
global preferences, or the current assistant task contract.
