# Iteration 16 User Stories

- As a learner, I upload a file once and can continue talking while its parsed
  reference is prepared in the background.
- As a learner, I see only source names and processing state in Sources, then
  choose exactly which ready source the teacher may use on my next message.
- As a learner, I know the teacher is bounded by the map topic description that
  created this learning unit.
- As a learner, I can approve a consolidation that turns our actual discussion
  into an opening, a coherent teaching manuscript, and optionally questions.
- As a learner, I can inspect teacher token use by learning conversation without
  seeing an implementation-facing assistant token dashboard.
