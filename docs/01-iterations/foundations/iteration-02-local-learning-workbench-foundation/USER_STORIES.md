# User Stories

## Story 1

As a serious learner, I want a learning topic to exist as a project with its own structure so that my study work is not trapped inside one-off task runs.

## Story 2

As a serious learner, I want to create subprojects under a parent topic so that I can go deep on one subject without losing the larger map.

## Story 3

As a serious learner, I want every project to come with Intro, Explain, Practice, Extend, and Summary zones so that my learning has a consistent structure.

## Story 4

As a serious learner, I want to invoke an agent from a zone and have it launch a real Claude Code terminal so that I can observe the authentic execution process.

## Story 5

As a serious learner, I want the system to automatically include predecessor file paths and behavior rules when invoking an agent so that the runtime has proper project context.

## Story 6

As a serious learner, I want to continue asking follow-up questions inside the same Claude session so that learning feels like a continuous investigation rather than disconnected tasks.

## Story 7

As a serious learner, I want the panel to append follow-up history instead of replacing earlier replies so that I can review my thinking trail.

## Story 8

As a serious learner, I want raw runtime traces and curated learning outputs to be stored separately so that my project files stay readable and my audit trail stays intact.

## Story 9

As a serious learner, I want Summary to remain editable and protected from blind AI overwrite so that my final knowledge stays learner-owned.

## Story 10

As a serious learner, I want project memory to begin recording what I already understand and where I struggle so that later outputs can become more targeted.

## Story 11

As a product maintainer, I want iteration 02 to establish the new project-session-artifact backbone so that later agents and UI polish can build on a stable architecture.
