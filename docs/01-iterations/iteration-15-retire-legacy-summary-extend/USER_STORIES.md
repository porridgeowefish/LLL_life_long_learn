# Iteration 15 User Stories

## US-15-01 — Current learning surface

As a learner, I use only Teacher, Assets, and Sources in a system-learning
project; I do not encounter retired Summary or Extend zones.

## US-15-02 — Retired garden is absent

As a learner, I cannot open, create, or edit a Knowledge Garden / knowledge
flower. It is no longer an implied part of my learning record.

## US-15-03 — History is safe

As the owner of an older project, retiring these features does not delete or
rewrite my existing `summary/` or `extend/` files.
