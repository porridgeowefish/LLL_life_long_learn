## Candidate capabilities

- Keep the five learning-stage agents; do not create a discipline × zone matrix.
- Explore composition of learning-stage agent × discipline protocol × local verification capability.
- Candidate epistemic families: formal reasoning, empirical inquiry, engineering construction, interpretive argument.
- Explore one primary plus at most one secondary protocol per project.
- Decide the user-facing selection and presentation before freezing the four-family model.
- Define how protocols select primitives, label evidence, adapt each zone, and refuse false verification claims.

### Lightweight learning lab

- Let Explain and Practice create reproducible local experiments.
- Explore Python, JavaScript, HTML preview, project-native tests, data analysis, math plots, and Mermaid.
- Define command preview, working-directory boundaries, timeouts, output limits, network policy, approval, and run history.
- Prefer an IDE bridge before attempting a complete embedded IDE.
