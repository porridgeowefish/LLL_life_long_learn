# Iteration 08 User Stories

Status: active
Owner: project maintainer
Last reviewed: 2026-07-14
Source of truth: delivered iteration 08 learner value.

## Learning rhythm

- As a learner, I can see both consistency and investment without being compared with others.
- As a learner, I can filter the rhythm by project and inspect what happened on a day.
- As a learner, my existing Practice growth remains visible in project and global totals.
- As a learner, agent automation does not inflate my learning history.

## Appearance

- As a learner, I can choose one of four calm, explicit themes.
- As a learner, my theme applies immediately, survives restart, and does not flash another theme first.
- As a learner with low vision or color-vision differences, text and state remain understandable without color alone.

## Open source

- As a user, I can reach the repository, report a problem, and find contribution guidance from the app.
