# User Stories

## Story 1

As a serious learner, I want to compose a structured AI study task from a browser UI so I do not have to manually switch between note tools and terminal prompts.

## Story 2

As a task operator, I want to see run status and logs in real time so I can trust what the AI runtime is doing.

## Story 3

As a study consumer, I want Markdown and Mermaid output rendered in the same app so I can review results immediately.
