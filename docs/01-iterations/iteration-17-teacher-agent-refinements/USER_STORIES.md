# Iteration 17 — User Stories

Status: planned
Owner: project maintainer
Last reviewed: 2026-09-11

## US-1 图片资料可被教师引用（OCR）

作为一个学习者，我上传讲义照片或截图并选择"保存并解析"后，希望资料里的文字
（含公式和表格结构）被提取成可引用文本，这样教师能在对话中直接引用图片内容，
而不需要模型本身具备视觉能力。

## US-2 生成中可以继续输入并排队

作为一个学习者，教师正在生成时我想到补充或追问，我希望输入框仍然可用；发送后
消息进入可见的等待队列，我可以编辑或删除它；当前回复结束后队列自动逐条发送，
刷新页面或换设备队列不丢。

## US-3 排队消息可以"立即引导"

作为一个学习者，当教师回答方向跑偏时，我希望能对某条排队消息点"立即引导"：
当前回答立即停下（已生成部分保留），教师带着我的引导内容继续，而不是等它把
错误方向写完。

## US-4 消息可复制、对话可导出

作为一个学习者，我希望悬浮任意消息能一键复制其 markdown 原文；对话头部有导出
按钮，把整段对话下载为一个 `.md` 文件（含角色、时间与附件名）。

## US-5 最后一条教师回复可重新生成

作为一个学习者，对最后一条教师回复不满意时，我可以点"重新生成"：旧稿隐藏
（不删除，历史可追溯），教师基于同一条提问重新回答。

## US-6 教师能搜索公网

作为一个学习者，问到时效性或事实性问题（如最新版本号、公开数据）时，我希望
教师能自主决定搜索公网，并在回答中给出来源链接；未配置搜索时教师行为与现在
完全一致。

## US-7 维护者能看懂仓库布局

作为一名维护本仓库的 agent/开发者，我希望根目录与脚本目录的分类一目了然：
运行脚本、开发工具、手工 QA、运行时数据各归其位，`learning-agents/` 不再与
coding agent 的概念混淆。
