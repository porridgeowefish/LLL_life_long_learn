# Iteration 07 User Stories

Status: active
Owner: project maintainer
Last reviewed: 2026-07-14
Source of truth: learner value and intended behaviors for iteration 07.

## US-07.1 Choose A Product Shape

As a learner, I want to explicitly choose a discipline map or system learning so that the product matches my current learning job.

## US-07.2 Ask AI For Choice Advice

As an uncertain learner, I want a temporary Ask AI conversation available before the form is complete so that I can clarify my intent and choose without saving another learning record.

## US-07.3 Build Orientation

As a learner approaching a broad field, I want one coherent discipline overview with a Word-like table of contents so that I can understand and navigate the field before committing to a branch.

## US-07.4 Keep Navigation Honest

As a learner, I want a discipline map to occupy the same folder-level position as my existing subject folders, with its overview opened from the folder title, so that navigation has one reusable mental model.

## US-07.5 Start A Deep Dive

As a learner, I want the create-learning action beside the exact concept or branch being explained in the overview body so that I can turn that local interest into a deliberate, prefilled learning commitment.

## US-07.6 Control Project Placement

As a learner, I want confirmed system-learning projects to use the existing folder membership and move controls while all project files remain flat, so that organization does not create a second ownership model.

## US-07.7 Preserve Existing Projects

As an existing learner, I want old projects to continue opening as system-learning projects so that the new model does not break prior work.

## US-07.8 Bridge A Prerequisite Gap

As a learner in an active lesson, I want AI to quickly explain only the missing prerequisite I need so that I can continue without opening another project.
