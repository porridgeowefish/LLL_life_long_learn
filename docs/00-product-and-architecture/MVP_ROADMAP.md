# MVP Roadmap

Status: draft  
Owner: project maintainer  
Last reviewed: 2026-06-04  
Source of truth: implementation order for the LLL MVP.

## Slice Order

```text
Iteration 01
Core orchestrator foundation: prompt compose, task launch, log monitoring, Markdown/Mermaid rendering.

Iteration 02
Task persistence and local history.

Iteration 03
Study artifact organization and export.

Iteration 04
Prompt pipelines, agent role presets, and reusable study jobs.

Iteration 05
Multi-source ingestion and structured study topic management.
```

## Definition Of MVP

The MVP is complete when a user can run repeatable learning workflows locally without switching among terminal, notes, and output readers by hand.
