# LLL PRD

Status: draft  
Owner: project maintainer  
Last reviewed: 2026-06-04  
Source of truth: product intent for the local AI learning lab.

## Problem

Serious learning with AI often breaks across too many surfaces:

```text
notes in one place
source materials in another
terminal agents in another
task progress in another
rendered study output nowhere stable
```

The result is friction, weak continuity, and poor review discipline.

## Product Goal

LLL should become a local-first learning operating system that:

```text
collects study context
dispatches AI task work
monitors execution
renders structured output
organizes iteration-by-iteration product progress
```

## Primary User

The primary user is a power learner who is comfortable with terminals and wants AI to act as a study operator, not just a chatbot.

## MVP Outcome

For a single study topic, the user should be able to:

```text
compose a structured task
launch Claude Code from the browser console
monitor task status and logs
read Markdown and Mermaid results in the same UI
capture the delivery contract for the next engineering slice
```
