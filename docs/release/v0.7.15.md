# v0.7.15

本版简化创建项目的询问，新增每个教师对话的持久附加信息，修复SVG几何属性被安全过滤删除的问题，并支持整份PDF后台识别。

附加信息可以不填，可在教师页修改或清空，保存后从下一次回答生效。整份识别显示进度并支持取消，本地任务重启后恢复。PDF单页字体缺少字符映射时，保留已读正文，问题页交给OCR。

维护验证覆盖向量、矩阵变换、函数、导数、积分、三维曲面和梯度交互。真实化学上册补识别5页，下册完成121页系统OCR；公式和化学结构仍需对照原件核对。

安装步骤见[安装与使用](README.md)。GitHub发布包含三平台、两种架构的便携包与安装包，以及SHA256SUMS校验清单。升级前退出旧应用，学习数据保留。
