# 批判性思考

## 机制

把学习者从主题的**接受式模型**推到**反事实与关系推理**：假设被打破会怎样、主题和兄弟主题怎么关联、模型在边界哪里失效。这是把主题从"听过"变成"有观点"的机制。理论基础：苏格拉底法 + 关系推理研究（Halford 1992）。

## 何时使用

- **必选** 拓展智能体。
- **不要** 在讲解上线前——反事实需要模型去扰动。
- **不要** 作为收尾点缀——批判性思考是拓展的**内容**，不是装饰。

## 输出形态

- **章节小标题**：`## 批判性追问`
- 三部分，各自独立子节：
  1. **反事实推演** — "如果 [承重假设] 为假，什么会先崩？" 2-3 段追踪级联后果
  2. **关系映射** — 命名一个兄弟主题、一个竞争主题；每个列 2 条结构相似 + 1 条结构差异
  3. **边界失效** — 描述一个具体边界情形，模型在该情形下产出错误或未定义，并说明这告诉学习者模型的适用域
- 总长 300-600 字

## 反模式

- **无级联的反事实**：写"如果 X 不同，情况会不同"——命名**什么**崩
- **关系映射只是名字列表**：必须命名**结构**相似，不是表面特征
- **用边界失效否定主题**：本 primitive 的目的是**暴露适用域**，不是 debunk

## 强制约束

- **全中文**：标题、术语全部中文。**禁止** "Critical Probe / Counterfactual / Relational Mapping / Failure Mode"。
- **禁止元对话**：不要"以下推演基于..."。

## 示例

```markdown
## 批判性追问

### 反事实推演
若光速不随观察者不变，麦克斯韦方程就必须依赖参考系。首先崩塌的是波动方程的**闭合**形式：c 依赖参考系时，方程多出一个观察者速度项，"电磁波"不再是参考系不变的对象。光在那个世界里更像声音——存在一个特权静止系...

### 关系映射
兄弟主题：无场的狭义相对论（纯运动学）。结构相似：都依赖洛伦兹变换；都用固有时为不变量。结构差异：纯运动学无场论对象。

### 边界失效
经典电动力学对点电荷算出无限自能。这不是数值问题；是模型告诉我们"点电荷超出我的适用域——你需要量子电动力学"。
```

真实级联、结构映射、命名失效。
