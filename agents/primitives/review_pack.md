# 复习材料

## 机制

把主题转成**紧凑、可自测的工件**供学习者后续复习。两层：费曼自测（不带笔记能讲清楚吗？）+ 概念理解闪卡（间隔压力下能否恢复关系、机制与边界）。没有这一层，前置 zone 产出理解但不产记忆。理论基础：测试效应（Roediger & Karpicke 2006）+ 间隔效应（Cepeda et al. 2008）。

## 何时使用

- **必选** 总结智能体。
- **不要** 在练习上线前——复习材料作用于**已学**层，不是原始讲解层。
- **不要** 作为总结本身的替代——本 primitive 是 `summary/summary.md` 的**伴侣**，不是替代。

## 输出形态

- `summary/flashcards.json`：8-15 张结构化理解卡，严格遵守 Summary charter 的 JSON 协议。
- `summary/review-pack.md`：3-5 条费曼清单 + 一句话复习节奏，不重复整套卡片。
- 闪卡内容配比建议：
  - 核心概念与机制：40%
  - 概念关系与因果：25%
  - 边界与反例：20%
  - 误解修正与迁移：15%

## 反模式

- **纯定义卡片**：Q"什么是 X？" A"X 是..."——考语言记忆不考理解。改问 X 为什么必要、如何与 Y 区分、何时不成立。
- **答案过短**：只给术语或关键词，无法重建推理链。
- **错题集冒充知识结构**：只根据 Practice 生成卡片，遗漏 Explain 的核心概念。
- **费曼条目太大**：写"解释狭义相对论"——拆小
- **无节奏**：清单不附节奏就只是列表

## 强制约束

- **全中文**：标题、术语全部中文。**禁止** "Review Pack / Feynman Checklist / SRS Cards"。
- **禁止元对话**：直接给清单 + 卡片 + 节奏。

## 好卡片示例

- 问：为什么 NFA 与 DFA 表达能力相同，但实现扫描器时通常选择 DFA？
- 答：子集构造保证两者识别同一语言；DFA 每个状态和输入只有唯一转移，可按字符线性查表执行，而 NFA 运行时需要跟踪状态集合。
- 类别：`relationship`
