# 边界映射

## 机制

显式列出**什么算本主题、什么不算、什么假设学习者已经懂**。没有边界映射，学习者要么把相邻内容误当本主题（过度延伸），要么漏掉本主题实际适用的地方。理论基础：原型理论的范畴边界（Rosch 1978）+ Star & Griesemer 的边界对象研究。

## 何时使用

- **必选** 讲解智能体的"边界"章节。
- **必选** 引入智能体——简化版，仅作框架。
- **不要** 单独使用——总要搭配正向定义，否则边界无参照。

## 输出形态

- **章节小标题**：`## 边界`
- 三个子节，**固定顺序**：
  1. **本主题包含** — 列出本主题实际涵盖什么（具体实例）
  2. **相关但不在范围** — 列出学习者易与本主题混淆的相关主题，每个一句话说明区别
  3. **前置知识** — 列出假设学习者已掌握的概念；每个前置应已在 `intro/output.md` 或其他前置 zone 中建立
- 每个列表 3-6 条，不更深
- 总长 150-400 字

## 反模式

- **模糊的"本主题包含"**：写"和 X 相关的一切"——命名具体实例
- **"相关"无区别**：列兄弟主题但不说明切分点
- **未定义的前置**：假设项目尚未建立的东西——直说"待补建"

## 强制约束

- **全中文**：标题、术语全部中文。**禁止** "Boundary Map / IN SCOPE / ADJACENT / PREREQUISITE"。
- **禁止元对话**：不要解释你在做什么、不要重复用户背景、不要"以下边界基于..."等。

## 示例

```markdown
## 边界

### 本主题包含
- SVD 的定义：$A = U\Sigma V^T$，三个矩阵的含义
- 奇异值的几何与代数直觉（大小排序、截断近似）
- 典型应用场景识别：降维、数据压缩、去噪、推荐

### 相关但不在范围
- **特征值分解 (EVD)** — 只适用于方阵；SVD 适用于任意矩阵，是 EVD 的推广
- **主成分分析 (PCA)** — PCA 的底层计算就是 SVD，但 PCA 关注的是统计解释

### 前置知识
- 矩阵乘法的几何含义（线性变换）
- 向量的长度与方向
- 正交的概念——**本项目将在讲解阶段从头构建**，标记为待补建
```
