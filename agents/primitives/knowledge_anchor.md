# 已有知识锚定

## 机制

把新主题**连接到学习者已经懂的东西**，作为新概念的入口面。新概念很少从零学起——它锚定在某个已知事物上，而锚点决定了后续可迁移多少。本 primitive 产出显式锚点陈述，让后续 agent（讲解 / 练习）能在此基础上构建而非从头推导。

## 何时使用

- **必选** 引入智能体。
- **不要** 单独使用——本 primitive 只为其他 primitive 铺路，不交付新内容。
- **不要** 当学习者确实无相关知识时——直说"无前置知识"并改产出"入口问题"。

## 输出形态

- **章节小标题**：`## 已有知识`
- 2-4 条锚点陈述，每条一段，包含：
  1. 学习者已经懂什么（命名具体概念）
  2. 这个已知和本主题有什么共通点（直接给出，不要解释为什么这么连）
  3. 这个锚点能让我们借鉴什么直觉
- 末尾一句话点出**缺口**——本主题需要从头构建、已知覆盖不到的部分。
- 总长 150-400 字。

## 反模式

- **无来源的锚点**：写"学习者懂 X"但没具体来源——不可验证。
- **模糊锚点**：写"学习者懂编程"——命名具体概念，不要笼统。
- **无迁移的锚点**：列出对本主题毫无借鉴的已知——浪费注意力。

## 强制约束

- **全中文**：标题、术语、解释全部中文。**禁止** 出现 "Knowledge Anchors / Relevance Hook / Gap note / Learner background" 等英文。
- **禁止元对话**：不要写"自述未接触"、"来源：通用数学经验"、"以下锚点基于..."、"learner..."等过程说明。**直接给内容**。

## 示例

```markdown
## 已有知识

- 你已用过"把复杂东西拆成简单部分再处理"的策略（因式分解、傅里叶变换）。本主题做的也是这件事——把矩阵拆成三个有几何含义的矩阵的乘积。
- 你已知矩阵可以"变换"向量（拉伸、旋转、投影）。本主题的核心洞察：任意矩阵变换都可分解为"旋转 → 拉伸 → 再旋转"三步。

缺口：以上未触及"正交"与"特征值"两个关键工具，本项目必须从头构建。
```
