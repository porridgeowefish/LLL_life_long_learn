# 第一性原理

## 机制

从**公理或已确立事实**推导到主题——不是从另一个定义推导。让学习者理解"为什么本主题必须是这样"，而不只是"它被定义成这样"。理论基础：亚里士多德第一性原理 + 现代工程实践（"从物理推演而非从类比推演"）。

## 何时使用

- **必选** 讲解智能体的"第一性原理"章节。
- **触发信号**：intent 含"为什么 / 本质 / 原理 / 基础"。
- **不要** 用于纯操作主题（如"如何 commit"）——改用 charter 内嵌实例。
- **不要** 当无真正共享公理时——直说，不要伪造推导。

## 输出形态

- **章节小标题**：`## 第一性原理`
- 开头一句话说明**起点公理**及其来源（物理 / 集合论 / 本项目已建立的前置主题）
- 5-8 步推理链，每步一段短文
- 每步必须显式"由 X 推出 Y，因为 Z"——不能跳跃
- 末尾一句话点**目的地**——点出本主题
- 总长 200-500 字

## 反模式

- **定义当起点**：开头写"X 定义为..."——这是循环，不是第一性原理
- **跳步**：从"众所周知..."直接跳到"所以本主题"——没有中间
- **类比冒充推导**：写"X 像邮局所以..."——类比是另一个 primitive（`analogy.md`）

## 强制约束

- **全中文**：标题、术语全部中文。**禁止** "First Principles / Topic Definition"。
- **禁止元对话**：直接给推导，不要"以下推演基于..."。

## 示例

```markdown
## 第一性原理

起点公理：在任何参考系下，光在真空中的速度对所有观察者相同（狭义相对论假设，Einstein 1905）。

1. 若光速不变而观察者可动，则"同时"不可能绝对——对一个观察者同时的两个事件，对另一个不一定同时。
2. 若同时相对，则时间间隔必然随参考系变化。
3. ...
目的地：洛伦兹变换——使 (1) 和 (2) 自洽的最小代数。
```

6 步、每步紧逼下一步、终点落到主题。
