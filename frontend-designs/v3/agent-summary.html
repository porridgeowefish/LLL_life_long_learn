Rust 所有权模型 · 学习总结

这是学习者主权文档。AI 可提议，但最终内容归我所有。

我已掌握的

所有权三条规则

  1. 每个值有且仅有一个所有者
  2. 同一时刻只能有一个所有者（赋值即移动）
  3. 所有者离开作用域 → 值被丢弃

我的理解：这是 Rust 用静态分析替代 GC 的根基。

移动语义

let s1 = String::from("hello");
let s2 = s1;  // s1 被移动
// s1 在此失效

最初觉得"反直觉"，但想清楚后很合理：避免双重释放。

借用与引用

  • 不可变借用 &T：可多个，只读
  • 可变借用 &mut T：只能一个，可写
  • 核心限制：可变借用和不可变借用不能同时存在

我仍困惑的

函数签名中的生命周期标注

fn longest<'a>(x: &'a str, y: &'a str) -> &'a str

计划：回讲解阶段重新过一遍"生命周期省略规则"段落。
