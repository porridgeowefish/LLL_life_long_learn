第 2 题 · 修复可变引用冲突

// 找出以下代码的所有权 bug 并修复 fn main() { let mut s = String::from("hi"); let r1 = &mut s; let r2 = &mut s; println!("{} {}", r1, r2); }
评审标准

  • 修复后零编译错误

这道题有问题？随时反馈：

问题诊断

这段代码违反了 Rust 的可变引用独占规则：在同一作用域中，一个值只能有一个可变引用。

这里同时存在 r1 和 r2 两个 &mut s，编译器在第 4 行就会拒绝编译。

修复方案

fn main() {
    let mut s = String::from("hi");

    // 方案 1：顺序使用，作用域隔离
    {
        let r1 = &mut s;
        println!("{}", r1);
    } // r1 在这里离开作用域
    {
        let r2 = &mut s;
        println!("{}", r2);
    }
}

为什么这样修

按借用规则，可变引用的生命周期结束后，新的可变引用才能诞生。
